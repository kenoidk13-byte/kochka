# KOCHKA — лендинг спортивного клуба

Тёмный брутал + кислотный лайм. Длинный скролл-лонгрид из 8 экранов, чистый HTML/CSS/JS без сборки и зависимостей.

## Запуск

Просто открыть `index.html` — или поднять локальный сервер (нужен из-за шрифтов/кэша):

```bash
cd kochka
python3 -m http.server 8765
# http://localhost:8765
```

## Экраны

| # | Секция | Что происходит |
|---|--------|----------------|
| 01 | Hero | прелоадер, шторка на фото, поэлементный выезд текста, вращающийся штамп, параллакс |
| 02 | Манифест | текст подсвечивается слово за словом по скроллу + счётчики цифр |
| 03 | Направления | строки с заливкой кислотным на hover и превью-фото, летящим за курсором |
| 04 | Тренеры | горизонтальный пин-скролл (секция «прилипает», карточки едут вбок) + прогресс |
| 05 | Расписание | табы по дням недели, пересборка строк с каскадной анимацией, «сегодня» подсвечено |
| 06 | Тарифы | переключатель месяц/год с анимацией цен |
| 07 | Пространство | коллаж с параллаксом и гигантская бегущая строка |
| 08 | Запись | форма с маской телефона и экраном успеха, контакты, огромный вордмарк в футере |

Плюс: кастомный курсор с blend-mode, магнитные кнопки, зерно, прогресс-бар, липкий CTA на мобиле, `prefers-reduced-motion`.

## Структура

```
index.html
assets/css/style.css   — вся вёрстка и анимации
assets/js/main.js      — лоадер, reveal, пин-скролл, расписание, цены, форма
assets/img/            — coach-1…5.jpg (из исходных PNG, сжаты в JPEG)
preview/               — 8 скриншотов секций 1440×900 (+ финал карусели тренеров) и полная мобильная версия
```

## Что менять под клиента

- **Фото** — `assets/img/coach-1..5.jpg` (3:4). Имена тренеров/подписи в `index.html` — заглушки (А. Волков, Д. Ким, М. Орлов, К. Штерн, С. Крамер), поставьте реальные.
- **Расписание** — массив `SCHEDULE` в `assets/js/main.js` (7 дней × 4 занятия).
- **Цены** — `data-price-month` / `data-price-year` у `.plan__price span`.
- **Тексты, адрес, телефон** — прямо в `index.html`.
- **Шрифты** — Oswald (заголовки), Manrope (текст), Playfair Display italic (акценты), подключены с Google Fonts.
